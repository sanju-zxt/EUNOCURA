# EUNOCURA backend — the demo path, pinned to what was actually tested.
#
# Pinned on purpose: the deployment (backend/Dockerfile, .do/app.yaml) must
# install the same versions this machine ran green, not whatever is newest at
# build time. Bump deliberately, then re-run `python tests/test_citations.py`.
#
# WHAT IS NOT HERE, AND WHY
# -------------------------
# torch, faiss-cpu, sentence-transformers, tiktoken and langchain-community used
# to be installed to support a vector store. The citation path does not use one:
# page text from pdfplumber plus literal quote matching answers "is this line on
# that page" exactly, and can be tested offline with no model at all. Removing
# the embedding stack cut install size from ~2.5 GB to well under 300 MB and made
# the verification step deterministic.
#
# They remain available for the legacy RAG module: requirements-optional.txt
#
# Speech (faster-whisper / pyttsx3 / pydub) is also optional. Without it the app
# runs in text-only mode and says so on /healthz.
